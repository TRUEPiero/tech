# Технобит: пакет для программиста

Дата: 07.09.2026. Пакет передачи 1.0. Основа - опубликованная версия сайта 9, включая последнее добавление вентиляторов в релейные группы.

## Задача

Перенести полезные блоки сайта и калькулятор в действующий сайт Технобит. Можно использовать компоненты React или перенести их поведение в технологию существующего сайта. Сохранить структуру этажей и комнат, автозаполнение, ручные правки, управление и экспорт JSON.

Для начала распакуйте ZIP целиком и откройте этот HTML-файл в браузере. Документы доступны в HTML для чтения и Markdown для редактирования. Интернет для чтения документов не требуется.

## Что изменилось в калькуляторе

| Раздел | Текущее поведение |
| --- | --- |
| Общее | Площадь объекта и наличие вентустановки. Производитель и модель не выбираются. |
| Свет | «Свет: релейные группы + умные розетки + вентиляторы», отдельно диммирование, DALI и LED. |
| Отопление | Радиаторы, водяной и электрический теплый пол, фанкойлы по комнатам. |
| Датчики | CO₂ для вентиляции; движение для света; количество мокрых зон для защиты от протечек. В комнате может быть несколько мокрых зон. |
| Кондиционеры | Есть / Нет в каждой комнате, без выбора модели. |
| Шторы | Общий счетчик штор, электрокарнизов, рулонных штор и жалюзи. |
| Управление | Независимый выбор P4/P6/P8, один сценарный выключатель: нет, 4, 6 или 8 клавиш. Под названием комнаты видны текущие количества света, отопления, штор и кондиционеров. |
| Типовые комнаты | Автозаполнение из 30 редактируемых шаблонов. P4 в прихожей и коридоре. Для остальных комнат начальные выключатели зависят от числа групп. |
| Итог и JSON | Количества обновляются сразу. Можно посмотреть и скачать текущую конфигурацию. |
| Запрос расчета щита | Отдельная кнопка, описание состава щита, выбор email / Telegram / WhatsApp и согласие. Подготавливается локальный JSON. |

Отдельных разделов выбора шаровых кранов и объединенной вкладки вентиляции с кондиционированием больше нет. Количество датчиков протечки и кранов должен определять будущий алгоритм по согласованным правилам.

## Граница готовности

Интерфейс, шаблоны и JSON реализованы. Автоматический подбор оборудования и итоговая цена еще не подключены. Сейчас estimate.totalRub = null, equipmentSeries = null, items = []. Умножать площадь на цены уровней автоматизации с главной страницы вместо подбора оборудования нельзя.

Согласовано: использовать РРЦ; Pro при площади дома больше 250 м², Lite при площади меньше 250 м²; для LED брать в среднем два канала на группу. Ровно 250 м², применение порога к квартирам, ряд комплектующих, пропусков в прайсе и правил подбора остаются открытыми. Подробности в CALCULATION_PROPOSAL.

Bitrix, email, Telegram, WhatsApp и Project Tool не подключены. Главная форма работает в демонстрационном режиме. Видео - заглушки. Подготовка пакета не включает публикацию на боевом сайте или предоставление доступа другим людям.

## Что сделать первым

1. Запустить исходники по PROGRAMMER_HANDOFF и изучить калькулятор.
2. Выделить компоненты и функции, которые будут перенесены в действующий сайт.
3. Подключить шаблоны к базе и авторизации действующего сайта. Сохранить проверку ревизии и запрет записи для посетителя.
4. Перенести интерфейс и JSON, пройти приемочные сценарии.
5. После согласования правил реализовать расчет оборудования с мгновенным обновлением суммы. Отправку и импорт в Project Tool подключать отдельным этапом.
