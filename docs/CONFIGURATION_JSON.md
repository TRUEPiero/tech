# JSON конфигурации Технобит

Версия формата: technobit.configuration.v1. Это предлагаемый формат передачи потребностей клиента. Он не заявлен как уже существующий API Project Tool.

## Где посмотреть

Внизу калькулятора, под блоком предварительной конфигурации: «Посмотреть JSON» и «Скачать JSON». Если сначала заполнить запрос расчета щита, в файл добавится один выбранный контакт. Файл создается в браузере, сохраняется в загрузки устройства и никуда не передается.

Примеры: [configuration-example.json](examples/configuration-example.json) - подготовленный запрос с вымышленным email; [configuration-draft.json](examples/configuration-draft.json) - та же конфигурация без контакта. Оба файла созданы функциями текущего приложения. Это иллюстрация структуры, а не проект клиента.

В примере два этажа и пять комнат, включая две отдельные спальни. Чтобы показать все варианты управления, вручную выбраны P6 в гостиной, выключатель на 6 клавиш в первой спальне и P8 вместе с выключателем на 8 клавиш во второй. Прихожая и кухня используют стартовое управление. Совместный выбор панели и выключателя допустим; типовые значения комнат описаны отдельно в ROOM_DEFAULTS.

## Структура

| Поле | Содержание |
| --- | --- |
| schemaVersion | Версия контракта, которую должен проверить получатель. |
| generatedAt | Время формирования снимка, ISO 8601. |
| source | Источник technobit-web-calculator. |
| configuration.areaM2 | Общая площадь в м²; null в незаполненном черновике. |
| configuration.objectSystems.ventilation.present | Наличие вентустановки на объекте. |
| configuration.floors[] | ID, тип, название, порядок этажа и его комнаты. |
| floors[].rooms[] | Отдельный ID каждой комнаты, тип, название с номером, порядок и системы. |
| rooms[].systems.lighting | relayAndSocketsGroups, dimmingGroups, daliGroups, ledGroups. relayAndSocketsGroups - общий счетчик релейного света, умных розеток и вентиляторов с включением/выключением; имя поля сохранено для совместимости. Единица - выбранная группа; это еще не количество аппаратных каналов. |
| rooms[].systems.heating | radiatorZones - зоны, waterFloorCircuits - контуры, electricFloorZones - зоны, fanCoils - устройства. |
| rooms[].systems.sensors | co2 и motion - количество датчиков; wetZones - количество мокрых зон, а не датчиков протечки. |
| rooms[].systems.curtains.drives | Количество управляемых штор, карнизов, рулонных штор или жалюзи. |
| rooms[].systems.airConditioner.present | Наличие одного кондиционера в комнате в рамках текущей формы. |
| rooms[].systems.controls | p4, p6, p8 - независимые признаки наличия одной панели каждого типа. scenarioSwitch - строка none, 4, 6 или 8: нет выключателя либо один выключатель с соответствующим числом клавиш. |
| configuration.totals | Суммы потребностей только выбранных комнат. Это не спецификация оборудования. |
| configuration.totals.panelsP4 / panelsP6 / panelsP8 | Количество выбранных панелей каждого типа по объекту. |
| configuration.totals.scenarioSwitches4 / scenarioSwitches6 / scenarioSwitches8 | Количество выключателей по типу, а не сумма их клавиш. |
| estimate | Место для будущего расчета оборудования. Сейчас статус pending_rules_approval, items = [], totalRub = null, equipmentSeries = null. Основа цены RRP, валюта RUB. |
| switchboardRequest | Отдельный запрос только на щит электрики и автоматики. |
| switchboardRequest.contact | null до подготовки запроса; после - channel, нормализованный value и consent = true. Передается только выбранный контакт. |
| switchboardRequest.delivery.status | not_sent. Контакт указан, но сообщение не отправлялось. |

## Правила получателя

- Управление добавлено как расширение формата v1. В новых файлах controls присутствует в каждой комнате. В старом файле отсутствие controls означает, что управление не было указано; не подменять это автоматически отсутствием устройств или текущим шаблоном комнаты.
- Для LED согласован средний расход двух каналов на группу. Поле lighting.ledGroups хранит исходное число выбранных групп. При подборе оборудования число каналов равно ledGroups × 2; для шестиканального модуля количество устройств округляется вверх после суммирования групп по объекту. В текущем экспорте подбор оборудования еще не выполняется.
- ID комнаты уникален внутри конфигурации. Не объединять помещения по одинаковому названию.
- Для связи с Project Tool потребуется отдельный идентификатор проекта/заявки. Текущие ID комнат локальны внутри конфигурации и не являются глобальными ID проектов. Авторизованного API импорта и постоянного хранения клиентских конфигураций пока нет.
- Все количества целые и неотрицательные. Пересчитать totals из rooms, если JSON приходит из внешнего источника.
- Проверять входящий файл на сервере. Суммы из браузера не являются доверенной ценой или разрешением на создание заказа.
- null означает отсутствие данных или расчета; не преобразовывать его в нулевую стоимость.
- При последующей интеграции сопоставить внутренние типы и единицы Project Tool с этими полями отдельной таблицей.
- После утверждения расчетов добавить версию прайса и правил, артикулы, количества устройств, РРЦ и итоги. Повторно рассчитать стоимость на сервере перед отправкой или фиксацией заявки.
- Контракт не содержит сведений о фактической отправке или успешном импорте в Project Tool. Такие статусы появятся только после реализации соответствующего подтверждаемого действия.

## Снимок и обновление

selectedConfiguration собирает потребности из текущего состояния комнаты. configurationExport формирует снимок с generatedAt в момент открытия просмотра или скачивания. После изменения калькулятора новый экспорт содержит новые значения. Уже скачанный JSON остается отдельным файлом; ранее открытый снимок не обновляется задним числом. Просмотр JSON доступен и для черновика без площади, но подготовка запроса щита требует положительную площадь и хотя бы одну комнату.

## Формат контакта

Email обрезается по краям и проверяется как адрес, максимум 254 символа. Telegram - имя пользователя из латинских букв, цифр и подчеркивания, начинается с буквы, длина без @ от 5 до 32; отсутствующий @ добавляется. WhatsApp - телефон с плюсом и кодом страны, от 8 до 15 цифр; пробелы, круглые скобки и дефисы убираются. Согласие передается как true. URL профиля Telegram и несколько контактов одновременно текущая форма не принимает.
